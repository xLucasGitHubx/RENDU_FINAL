🛠️ Méthodologie

Pipeline en 5 étapes, reproductible depuis le notebook carte-dynamique.ipynb :

  • Chargement : contours GeoJSON (gregoiredavid/france-geojson) + données SPF hospitalières
  • Jointure : codes département à 2 chiffres, agrégation régionale via table INSEE
  • EDA : statistiques descriptives, top départements, matrice de corrélation
  • Clustering : K-Means sur features standardisées, choix de k par silhouette ; dendrogramme hiérarchique (Ward) en complément
  • Cartographie : 4 cartes Folium dont une Dual Map synchronisée
Python 3.12 Folium GeoPandas scikit-learn Pandas SciPy
